📁 基础入门：文件与目录操作 (Basic Navigation & File Ops)

5 个常用场景
BASIC目录查看与快速切换pwd, cd, ls 高频选项
# 查看当前工作目录物理真实路径
pwd -P

# 快速返回上一次所在目录
cd -

# 列表详细查看：包含隐藏文件、人类可读文件大小、长 ISO 时间格式
ls -lha --color=auto --time-style=long-iso /opt/app
cd - 是终端频繁在两路径切换时最出色的效率黑科技
BASIC创建与删除目录/文件mkdir, touch, rm 规范用法
# 递归创建多级目录结构（如父级目录不存在会自动创建）
mkdir -p /opt/app/logs/2026

# 创建空文件或更新已存在文件的修改时间戳
touch /opt/app/logs/2026/app.log

# 递归强制删除目录（请务必核对路径，避免 rm -rf /）
rm -rf /tmp/old_build_dir

# 交互式删除（每删一个文件弹窗确认，适合敏感文件）
rm -i /opt/app/config.json
mkdir -p 保证脚本在初始化深度文件夹路径时绝不会报错报错退出
BASIC复制、移动与重命名cp, mv 归档与覆盖策略
# 归档模式复制目录：保留属主、权限、时间戳及软链接属性
cp -ra /var/www/html/ /var/www/html_backup/

# 仅当源文件更新或者目标文件不存在时才执行复制 (Update 模式)
cp -u config.prod.json /opt/app/config.json

# 移动或重命名文件/目录，并打屏显示过程
mv -v /opt/app/app.log.old /opt/app/app.log.bak
备份目录推荐使用 cp -ra，完美避免文件修改时间与属主信息丢失
BASIC精准查找文件与程序定位find, whereis, which
# 按文件名通配、最近 7 天内修改、且文件大于 100M 查找日志
find /var/log/nginx/access.log -name "*.log" -mtime -7 -size +100M

# 查找当前目录下所有 .sh 脚本并批量修改为 755 权限
find . -type f -name "*.sh" -exec chmod 755 {} +

# 查找某个可执行命令的绝对路径与帮助文档路径
which nginx
whereis nginx
find ... -exec ... {} + 批量处理效率远比 xargs 更安全高效
BASIC软链接与硬链接创建ln -s 快捷方式管理
# 创建符号软链接（快捷方式，推荐使用绝对路径）
ln -s /var/log/nginx/access.log /tmp/current_access.log

# 查看软链接指向的目标实际路径
ls -l /tmp/current_access.log

# 强制覆盖替换已存在的软链接
ln -snf /var/log/nginx/access_2026.log /tmp/current_access.log
修改更新软链接时务必使用 ln -snf 避免误将链接创建到目标目录内部

📝 文本查看与流式处理 (Text Processing & Inspection)

5 个常用场景
TEXT高效查看与实时日志追踪cat, less, tail, head
# 实时动态追踪日志文件最新的 200 行
tail -fn 200 /var/log/nginx/access.log

# 交互式查看长日志：显示行号、自动定位至文件底部 (按 q 退出)
less -N +G /var/log/nginx/access.log

# 查看文件前 30 行内容
head -n 30 /var/log/nginx/access.log
less -N +G 打开大型几GB文件极快且不会内存溢出
TEXT正则匹配与强大过滤grep 常用参数组合
# 递归、忽略二进制、显示行号高亮搜索 "ERROR" 关键字
grep -rnI --color=auto "ERROR" /var/log/nginx/access.log

# 过滤配置文件：排除以 # 开头的注释行以及空白空行
grep -v "^#" /etc/nginx/nginx.conf | grep -v "^$"

# 扩展正则表达式：同时匹配 500/502/504 错误状态码
grep -E " 500 | 502 | 504 " /var/log/nginx/access.log
grep -v "^#" | grep -v "^$" 是阅读干净纯粹配置文件的利器
TEXT流编辑器文本替换与截取sed 原地修改与指定行打印
# 在原文件直接全局替换 IP 地址（配合 .bak 自动产生备份）
sed -i.bak 's/127.0.0.1/192.168.1.100/g' /etc/nginx/nginx.conf

# 快速截取并打印文件的第 100 行至第 150 行
sed -n '100,150p' /var/log/nginx/access.log

# 直接在原文件中删除包含 "DEBUG" 的所有调试日志行
sed -i '/DEBUG/d' /var/log/nginx/access.log
sed -i.bak 在做配置修改前能自动备份原文件，运维更安全
TEXT日志分析与字段数据处理awk 提取、统计与计算
# 分析 Nginx 访问日志，统计请求频次最高的 Top 10 IP 地址
awk '{print $1}' /var/log/nginx/access.log | sort | uniq -c | sort -rn | head -n 10

# 以冒号分割，提取 UID 大于等于 1000 的普通用户账号和主目录
awk -F':' '$3 >= 1000 {print $1, $3, $6}' /etc/passwd

# 累加日志第 10 列传输字节数并计算 MB 总量
awk '{sum += $10} END {print "Total Transfer:", sum/1024/1024, "MB"}' /var/log/nginx/access.log
awk '{print $1}' | sort | uniq -c | sort -rn 为最经典的日志分析管道套路
TEXT列切割、排序去重与差异比对cut, sort, uniq, diff
# 按逗号切割，提取 CSV 文件的第 1 列和第 3 列
cut -d',' -f1,3 data.csv

# 快速统计日志文件总行数、词数与字节数
wc -l /var/log/nginx/access.log

# 统一上下文比对两个配置文件的差异 (Unified diff)
diff -u /etc/nginx/nginx.conf /etc/nginx/nginx.conf.bak
diff -u 输出格式符合 Git 提交标准，对比配置一目了然

📊 系统监控与进程管理 (System Health & Process Control)

5 个常用场景
SYS进程排查与层级拓扑树ps, top, htop 监控
# 查看全量进程列表并筛选 Nginx 相关进程
ps aux | grep nginx

# 以树状结构展现所有父子进程关系
ps -ef --forest

# 批处理模式单次快照查看资源占用前 15 位的进程
top -b -n 1 | head -n 22
ps -ef --forest 能够极其清晰地分辨出子进程是由哪个主进程 Fork 出来的
SYS进程终止与信号发送kill, pkill, killall 安全清理
# 优雅终止进程（发送 SIGTERM 15 信号，允许进程保存清理数据）
kill -15 12345

# 强制杀死死锁或未响应进程（SIGKILL 9 信号）
kill -9 12345

# 根据进程完整命令行搜索并批量终止程序
pkill -f "python3 app.py"
生产环境切勿直接无脑 kill -9，应优先尝试 kill -15
SYSSystemd 服务管理与日志诊断systemctl, journalctl
# 查看服务运行状态、开机自启状态与最新日志片段
systemctl status nginx

# 设置开机自启并立即启动服务
systemctl enable --now nginx

# 实时追踪系统服务底层日志（无分页直接刷屏）
journalctl -u nginx -n 100 -f --no-pager
systemctl enable --now 可一条命令完成开机自启 + 立即启动
SYS内存、CPU 负载与核心硬件free, uptime, lscpu
# 查看物理内存、Swap 分区及 Buffer/Cache 占用（G/M 人类可读单位）
free -h -t

# 查看系统运行时长以及 1m/5m/15m 平均负载 Load Average
uptime

# 查看物理 CPU 核心数、线程数、架构与 CPU 频率
lscpu
当 Load Average 数值持续高于 CPU 总逻辑核心数时说明系统过载
SYS磁盘空间挂载与大文件排查df, du, lsblk
# 查看磁盘各挂载点空间、文件系统类型及 inode 使用率
df -hT -i

# 递归查找根目录下占用空间最大的前 10 个顶级文件夹（排除报错）
du -sh /* 2>/dev/null | sort -rh | head -n 10

# 查看系统全量块设备、UUID 与挂载对应关系
lsblk -f
df -i 排查 inode 耗尽（磁盘虽有剩余容量却无法新建文件）极管用

🌐 网络通信与远程运维 (Networking, Ports & Remote Ops)

5 个常用场景
NET端口监听与连接句柄查询ss, netstat, lsof, nc
# 查看本地监听的 TCP/UDP 端口及所对应的程序 PID
ss -tulpn | grep :80

# 精准反查占用 8080 端口的进程详细信息
lsof -i :8080

# 测试远程目标服务器的指定 TCP 端口连通性
nc -zv 192.168.1.100 80
ss 比传统的 netstat 在连接数极大时性能高出百倍
NET网络抓包与 DNS 诊断tcpdump, ping, dig
# 在 eth0 网卡抓取 80 端口的 HTTP 数据包并保存为文件
tcpdump -i eth0 -n port 80 -w capture.pcap

# 快速测试 ICMP 网络连通（仅发送 4 个数据包）
ping -c 4 192.168.1.100

# 深入解析域名的 A 记录解析过程与 DNS 响应
dig +short A www.baidu.com
抓取的 `.pcap` 文件可直接用 Wireshark 导入可视化图形分析
NETHTTP 请求测试与文件下载curl, wget 常用调试
# 发送带 Header 与 JSON 数据的 POST 请求（显示请求与响应头细节）
curl -iv -X POST -H "Content-Type: application/json" -d '{"status":"active"}' http://192.168.1.100:8080/api

# 静默测试 URL 连通性并输出 HTTP 状态码
curl -sIL http://192.168.1.100

# 断点续传方式下载大文件并保存为新名称
wget -c -O package.tar.gz http://example.com/file.tar.gz
curl -sIL 输出 301/302 重定向全链路信息，排查 CDN 非常方便
NETSSH 远程登录与密钥部署ssh, ssh-copy-id, 隧道
# 指定密钥文件与非标准端口登录远程主机
ssh -i ~/.ssh/id_rsa -p 22 root@192.168.1.100

# 将本机公钥推送部署至远程服务器（实现后续免密登录）
ssh-copy-id -i ~/.ssh/id_rsa.pub root@192.168.1.100

# 建立 SSH 端口转发隧道：将远端 80 端口映射到本地 8080
ssh -N -L 8080:localhost:80 root@192.168.1.100
ssh-copy-id 自动设置 ~/.ssh/authorized_keys 正确的 600 权限
NET远程文件传输与增量同步scp, rsync 同步架构
# 通过加密通道将本地目录递归复制到远程服务器
scp -r -P 22 ./dist root@192.168.1.100:/var/www/html/

# 增量同步：带压缩、进度显示，且自动删除远程多余废弃文件
rsync -avzP --delete ./dist/ root@192.168.1.100:/var/www/html/
部署静态网页项目强烈推荐 rsync -avzP --delete，速度远快于 scp

🔒 用户权限与归档解压 (Permissions, Users & Archives)

3 个常用场景
PERM文件权限与所有者变更chmod, chown 赋权策略
# 递归变更目录及其子文件的所有者与属组
chown -R www-data:www-data /var/www/html/

# 递归设置标准权限：目录 755 (rwxr-xr-x)
chmod -R 755 /var/www/html/

# 紧固私钥文件安全权限（仅属主可读写，防止 SSH 报 Unprotected key 警告）
chmod 600 ~/.ssh/id_rsa
SSH 私钥必须保持 600 权限，否则 SSH 客户端将拒绝使用该密钥
PERM用户创建与 sudo 提权管理useradd, usermod, visudo
# 创建新用户：自动创建主目录且指定默认 Bash Shell
sudo useradd -m -s /bin/bash deploy

# 将已有用户追加到特定附加组（如 docker 组，无需重新登录）
sudo usermod -aG docker deploy

# 安全编辑 sudoers 配置文件（自动语法校验，避免编辑错误锁死系统）
sudo visudo
切记编辑 sudoers 一律使用 visudo 命令，防止配置错误失去管理员权限
PERM打包、压缩与解压缩tar, gzip, zip 跨平台归档
# 打包并使用 Gzip 格式压缩指定文件目录
tar -czvf /opt/app_backup.tar.gz /var/log/nginx/access.log

# 解压 .tar.gz 文件到目标文件夹
tar -xzvf /opt/app_backup.tar.gz -C /tmp/extract/

# zip 跨平台压缩与静默解压
zip -r archive.zip /opt/app/
unzip -q archive.zip -d /tmp/extract/
记忆口诀：打包压缩用 -czvf，解包解压用 -xzvf

🔥 进阶运维与 Shell 调试黑科技 (Advanced Ops & Shell Debugging)

5 个常用场景
ADV重定向、管道与后台守护nohup, tee, 2>&1 深入详解
# 后台守护运行程序：标准输出与标准错误全部合并重定向输出到日志文件
nohup python3 app.py > /var/log/nginx/access.log 2>&1 &

# 管道追加写入文件，同时在控制台终端打屏输出
echo "Deployment complete: 2026-07-21" | tee -a /var/log/nginx/access.log
2>&1 含义为将标准错误（文件描述符 2）重定向复制到标准输出（文件描述符 1）
ADV定时任务与终端会话保持crontab, tmux, screen
# 编辑当前用户的定时任务 Cron 规则 (分 时 日 月 周)
crontab -e

# 经典 Crontab 样例：每天凌晨 02:00 自动执行备份脚本
0 2 * * * /opt/backup.sh > /dev/null 2>&1

# Tmux 终端持久化会话：即使网络断开后台任务也不会中断
tmux new -s mysession     # 创建新会话
tmux attach -t mysession  # 重新连接已有会话
在 SSH 远程连接编译大型项目时，强烈建议开启 tmux 防止掉线挂断
ADV环境变量与 Shell 快捷缩写export, alias, source
# 导出追加环境变量 PATH
export PATH=$PATH:/usr/local/go/bin

# 设置常用命令缩写别名 (可写入 ~/.bashrc 永久生效)
alias ll='ls -alF --color=auto'
alias ports='ss -tulpn'

# 重新加载 Bash 配置文件，使其在当前窗口立即生效
source ~/.bashrc
为高频长命令配置 alias 能够极大提升每日运维操作速度
ADV磁盘 I/O、内存 Swap 与内核错误排查iostat, vmstat, dmesg
# 查看磁盘读写 IOPS、MB/s 及 %util 饱和度 (每秒刷新一次，共 5 次)
iostat -xz 1 5

# 监控系统上下文切换 cs、中断 in 及内存 Swap 进出情况
vmstat 1 5

# 带时间戳查看内核底层硬件及 OOM (Out of Memory) 内存溢出日志
dmesg -T --level=err,warn | tail -n 30
当 iostat 中的 %util 接近 100% 时，说明磁盘 I/O 已经达到性能瓶颈上限
ADV系统调用追踪与句柄文件诊断strace, lsof 高级分析
# 实时跟踪某个 PID 进程的文件与网络系统调用及单次耗时
strace -p 12345 -e trace=file,network -T -tt

# 列出指定进程当前打开的所有文件描述符、Socket 句柄及磁盘文件
lsof -p 12345

# 统计系统全量已打开的文件句柄总数
lsof | wc -l
strace 是排查程序卡死、无法读取配置文件等挂起问题的最终武器
